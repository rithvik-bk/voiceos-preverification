PREFLIGHT · PROOF-CARRYING ACTIONS

The Setup

A deterministic pre-verification layer for voice-agent tool calls. Before any action fires, every routing parameter — who / where / when / how much — must trace to a licensed source, or the action has no valid form to exist in. Zero LLM in the hot path. Same input, same verdict, forever.

Every verdict on this page is produced by the real @preflight/core gate. Rendered from packages/demo/trace.json — not hand-faked.

Honest scope — stated up front

  • The money case here is caught because the recipient is ungrounded (the injection firewall). Core also checks amounts against the spoken number-set: an amount never spoken (54.99 ∉ {54.79}) blocks with amount_not_in_speech (see amount-catch.mjs and core test/misbinding.test.ts). Dollar figures are scenario ground-truth — the amount the bad call would have moved — clearly labeled, never gate-computed.
  • Preflight is structurally blind to ASR-mishear: it grounds what was transcribed; it does not second-guess transcription. That is a read-back-confirmation problem, a different layer.
  • Content parameters (what to say) are never provenance-blocked — surfaced for consent, not gated. Only routing parameters are proof-carrying.
