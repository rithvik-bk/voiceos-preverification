# @preflight/demo

Runnable, offline, deterministic demos of Preflight. Every verdict shown is produced by the real
`@preflight/core` gate — nothing is hand-faked — and there is no `Date.now`/`Math.random` anywhere,
so each script prints byte-identical output every run. The scripts also emit static HTML/JSON traces
(rendered from the same gate output) for a visual walkthrough. These are demos of a **prototype**.

## Files

| File | What it does |
|---|---|
| `run.mjs` | "The Setup" — a two-pane demo (VoiceOS alone vs VoiceOS + Preflight) over four scenes exercising the injection firewall, ambiguous target, hallucinated target, and a clean PASS; writes `trace.json`, `setup.html`, and `panel.html`. |
| `amount-catch.mjs` | The `$54.79 → $54.99` catch: you say `$54.79`, the model re-types the refund as `$54.99`, and the gate holds because `54.99` was never in the spoken number-set (`amount_not_in_speech`). |
| `autonomy.mjs` | The multi-step **prototype** — runs `verifyPlan` over an 11-step autonomous plan (DAG), classifying each step auto-run / hold / block / deferred, and shows the autonomy dial; writes `autonomy-trace.json` and `autonomy.html`. |
| `setup.html` | Generated by `run.mjs` — the visual "Setup" walkthrough (rendered from `trace.json`). |
| `panel.html` | Generated by `run.mjs` — a live-stats panel fed by `packages/eval/results/*.json` (per-corpus, never blended). |
| `autonomy.html` | Generated by `autonomy.mjs` — the visual proof-tree of the 11-step plan. |
| `trace.json`, `autonomy-trace.json` | The emitted gate traces the HTML pages render from. |

## Run the demos

```
cd packages/demo
node run.mjs           # The Setup (4 scenes) → also writes trace.json / setup.html / panel.html
node amount-catch.mjs  # the $54.79 → $54.99 catch
node autonomy.mjs      # the multi-step plan prototype → also writes autonomy-trace.json / autonomy.html
```

Determinism check:

```
node run.mjs > /tmp/a && node run.mjs > /tmp/b && diff /tmp/a /tmp/b   # identical
```

The `panel.html` stats come from the eval artifacts, so run `@preflight/eval` first if you want that
pane populated with fresh numbers.
